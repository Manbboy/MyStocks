Pour enregistrer tes valeurs, la page a besoin d'un jeton d'accès limité à ton dépôt :

  1. Ouvre github.com/settings/personal-access-tokens/new

  3. Repository access : Only select repositories →
  4. Permissions → Repository → Contents : Read and write
  5. Generate token, copie-le et colle-le ici
